# GoWork - אפליקציית עובדי שטח

אפליקציה מובילה לניהול עבודות שטח, מלאי ותיעוד עבור טכנאים, מתקינים ועובדי שירות.

## ✨ תכונות עיקריות

### 👤 ניהול משתמשים
- הרשמה והתחברות עם בחירת תפקיד (מנהל/עצמאי/עובד)
- קלט קולי לשדות שם ואימייל
- ניהול פרופיל אישי והגדרות

### 📦 ניהול מלאי
- הוספה והסרה של פריטי מלאי
- סריקת ברקוד/מספר סריאלי באמצעות OCR
- תמיכה בצילום ובהעלאת תמונות
- פקודות קוליות להוספה והסרה
- סטטוס פריטים: חדש, פגום, מחודש
- סיכום מלאי עם כמויות וחיפוש מתקדם

### 📝 תיעוד עבודה
- יצירת דוחות עבודה מפורטים
- קלט קולי לכל השדות
- חתימה דיגיטלית של לקוחות
- צילום תמונות דרך המצלמה
- שמירת פרטי לקוח, כתובת ותיאור עבודה

### ⏰ תזכורות חכמות
- הוספת תזכורות בטקסט או קול
- זיהוי אוטומטי של תאריכים (למשל: "10.8 רופא שיניים")
- התראות יום לפני המועד
- מיון לפי סטטוס: היום, קרובות, עברו

### 📞 דיווחי לקוחות
- שליחת דיווחי בעיות ותלונות ללקוחות
- תבניות מהירות לבעיות נפוצות
- קלט קולי לתיאור הבעיה
- מעקב אחר סטטוס הדיווחים

### 🎛️ לוח בקרה מותאם
- תצוגה שונה לכל תפקיד (מנהל/עצמאי/עובד)
- סיכום נתונים ופעילות אחרונה
- גישה מהירה לפונקציות עיקריות

## 🚀 התקנה והפעלה

### דרישות מערכת
- Node.js 16+ 
- NPM או Yarn

### התקנת התלויות
```bash
npm install
```

### הפעלת השרת הפיתוח
```bash
# הפעלת שרת הפיתוח (React)
npm run dev

# הפעלת שרת הבקאנד (Express) - בטרמינל נפרד
npm start
```

האפליקציה תהיה זמינה בכתובת: `http://localhost:3000`
שרת הבקאנד יפעל בכתובת: `http://localhost:5000`

## 🎨 עיצוב ונגישות

### תמיכה בעברית
- כיוון RTL מלא
- גופנים תומכי עברית
- תרגום מלא לעברית

### עיצוב מותאם לעובדי שטח
- צבעים רכים ומקצועיים
- ממשק נקי ופרקטי
- גישה מהירה לפונקציות חיוניות
- תצוגה מותאמת למובייל

### נגישות
- תמיכה בקלט קולי
- כפתורים גדולים וברורים
- ניווט אינטואיטיבי

## 🔧 טכנולוגיות

### Frontend
- React 18
- React Router Dom (ניתוב)
- Axios (קריאות API)
- React Signature Canvas (חתימה דיגיטלית)
- Date-fns (ניהול תאריכים)
- Web Speech API (קלט קולי)

### Backend
- Express.js
- Multer (העלאת קבצים)
- File system storage

### סטיילינג
- CSS3 עם Custom Properties
- Flexbox ו-Grid
- רספונסיבי מלא

## 📱 תכונות מובייל

- **צילום**: גישה למצלמת הטלפון לצילום ישיר
- **OCR**: זיהוי מספרים סריאליים מתמונות
- **קלט קולי**: תמיכה ב-Web Speech API
- **חתימה דיגיטלית**: חתימה על מסך המגע
- **תזכורות**: התראות דרך הדפדפן
